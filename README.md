# Совет трейдеров — Telegram Mini App (демо)

Девять ботов обсуждают рынок и принимают общее решение. **Только демо:** цены настоящие (публичные API Binance → OKX → Bybit, без ключей), баланс виртуальный (по умолчанию 10 000 USDT), сделки симулируются (комиссия 0,1%). Нет кошелька, ордеров и приватных ключей.

| Бот | Стратегия |
|---|---|
| 📈 Трендовик | EMA 9/21: разрыв, свежее пересечение, наклон EMA21 |
| 🔄 Контрарианец | RSI 14 и отклонение от SMA20 (возврат к среднему) |
| 📊 Объёмщик | OBV за 10 свечей, всплеск объёма к среднему за 20 |
| 🔍 Дивергент | Бычья/медвежья дивергенция RSI и MACD (заменил Волатильщика) |
| 🗞️ Новостник | Контртренд по настроению: Fear & Greed (крипта), лента Yahoo (США); по Мосбирже — импульс как прокси |
| 📐 Уровневик | Поддержка и сопротивление: свинг-экстремумы и пивоты, отскок или пробой |
| 🌊 Флетовик | Возврат к среднему во флете, в тренде голос тише (заменил Свечника) |
| 🛡️ Риск-менеджер | Риск % от баланса, стоп 1,5×ATR, тейк 2R, право вето; пауза 2 ч после стопа, минимальная выдержка 60 мин |
| ⚖️ Арбитр | Взвешенная сумма голосов (веса по проверенному краю), вход при счёте ≥ 0,25 |

Раунд: арбитр открывает → 7 аналитиков дают аргументы → отвечают самым несогласным → риск-менеджер считает позицию или накладывает вето → арбитр подводит итог. Торговля только «лонг» (спот): покупка открывает позицию, продажа закрывает; стоп/тейк проверяются каждые 20 с.

TON на биржах сейчас торгуется под тикером **GRAM** — котировки берутся по нему.

## Режимы
- **Статический (GitHub Pages)** — папка `public/`. Цены браузер берёт прямо с бирж, состояние — в Telegram CloudStorage (на пользователя) + localStorage.
- **С сервером** — `node server.js` (Node 20, без зависимостей): прокси цен, хранение состояния по Telegram user id в `/data/users`. Переменные: `PORT`, `DATA_DIR`, `BOT_TOKEN` (если задать — initData проверяется по подписи), `LLM_API_KEY`/`LLM_BASE_URL`/`LLM_MODEL` (необязательно: «живой» текст реплик через OpenAI-совместимый API). `amvera.yml` готов.

## Подключение к Telegram (@BotFather)
1. Откройте @BotFather → `/newbot` → имя и username бота (оканчивается на `bot`).
2. Кнопка меню: `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → **Configure menu button** → отправьте URL приложения → название кнопки, например «Совет трейдеров».
3. (Необязательно) полноценный Mini App со ссылкой `t.me/<бот>/<имя>`: `/newapp` → выберите бота → название, описание, картинка 640×360 → URL приложения → короткое имя (например `council`).
4. Откройте бота в Telegram и нажмите кнопку меню — приложение откроется внутри Telegram, счёт привяжется к вашему Telegram-аккаунту.

Проверка: `python3 e2e.py <url>` (headless Chrome, экран 390×844, раунд совета, сделка, скриншоты).
